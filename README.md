# מחשבון חיסכון חודשי

סקריפט קטן בפייתון שמחשב כמה כסף יצטבר מחיסכון חודשי קבוע.
הפרויקט נועד להתנסות בעבודה עם Branches ב-Git וב-GitHub.

## הרצה
```
python savings.py
```

## יכולות
- חישוב בסיסי: חיסכון חודשי כפול מספר החודשים.
- ריבית שנתית דריבית (מחושבת חודשית).

## שימוש
1. מריצים `python savings.py`.
2. מזינים סכום חיסכון חודשי ומספר שנים.
3. מזינים ריבית שנתית באחוזים (0 אם אין ריבית).
4. התוכנית מדפיסה את הסכום שנצבר.
